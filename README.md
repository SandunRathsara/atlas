# Atlas

This repository contains the first runnable Atlas slice: a private, server-rendered sign-in and shell.

## Run locally

Requires Bun `1.3.14`.

```sh
export ATLAS_SHARED_TOKEN="use-a-local-secret"
export ATLAS_ORIGIN="http://localhost:3000"
bun install --frozen-lockfile
bun run dev
```

Open `http://localhost:3000`. The server refuses to start without `ATLAS_SHARED_TOKEN`.

`ATLAS_ORIGIN` is optional for local use and should be the private HTTPS origin in deployment. The browser cookie is always `Secure`, `HttpOnly`, host-only, `SameSite=Strict`, and expires after seven days without sliding. HTTP clients may use `Authorization: Bearer "$ATLAS_SHARED_TOKEN"`.

The CSS asset is generated by `bun run build:css`; no frontend component framework or database is used in this slice.
